QUICK DEPLOYMENT (30 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Build the application

  cd backend
  npm run build
  cd ..

STEP 2: Prepare Render deployment

  1. Go to https://render.com
  2. Sign up with GitHub
  3. Click "+ New" → "Web Service"
  4. Select your GitHub repository
  5. Fill in:
     Name:           codingcon-backend
     Runtime:        Node
     Build Command:  cd backend && npm install && npm run build
     Start Command:  cd backend && npm start
  6. Click "Advanced" and add environment variables (see STEP 3)

STEP 3: Add Environment Variables to Render

  Go to Settings → Environment → Add these:

  NODE_ENV=production
  PORT=4000
  MONGODB_URI=mongodb+srv://monishlegend1780_db_user:6yBIRY2LLGfa2PLP@cluster0.juix7su.mongodb.net/codingcon?appName=Cluster0&retryWrites=true&w=majority
  JWT_SECRET=<generate-strong-key>
  JWT_EXPIRES_IN=7d
  CORS_ORIGIN=https://your-app.vercel.app
  CLUSTER_ENABLED=true
  WORKERS=4
  DB_POOL_SIZE=50
  DB_MIN_POOL_SIZE=10
  MAX_JUDGE_JOBS=4
  QUEUE_CONCURRENCY=2
  CRON_SECRET=<generate-strong-key>
  RABBITMQ_URL=
  REDIS_URL=

  Generate strong keys:
    node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

STEP 4: Deploy Frontend to Vercel

  1. Go to https://vercel.com
  2. Import your GitHub repository
  3. Add environment variable:
     NEXT_PUBLIC_API_URL=https://your-backend-url.onrender.com
  4. Deploy

STEP 5: Verify Deployment

  ✓ Backend health: https://your-backend.onrender.com/api/health
  ✓ Frontend: https://your-app.vercel.app
  ✓ Login test: Use student@cit.edu / student123

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Backend deployment fails
  Solution: Check Render logs for build errors
  - npm run build works locally?
  - All dependencies in package.json?

Problem: "MongoDB connection refused"
  Solution: Check MongoDB Atlas IP whitelist
  - Go to cluster → Security → Network Access
  - Add Render IP or use 0.0.0.0/0

Problem: Frontend can't reach backend
  Solution: Update environment variables
  - Render: CORS_ORIGIN = Vercel URL
  - Vercel: NEXT_PUBLIC_API_URL = Render URL

Problem: Code submissions hang
  Solution: Check judge worker is running
  - Render logs should show "Judge worker ready"
  - Check if Docker is available (might not be on Render)

Problem: WebSocket disconnecting
  Solution: Check Socket.IO logs
  - Browser console for WebSocket errors
  - Backend logs for connection issues
