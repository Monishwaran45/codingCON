═══════════════════════════════════════════════════════════════════════════════
1. RABBITMQ - MESSAGE QUEUE
═══════════════════════════════════════════════════════════════════════════════

What it does: Queues up jobs (like code submissions) so they don't block users

Setup (5 minutes):
────────────────────────────────────────────────────────────────────────────

1. Go to: https://www.cloudamqp.com/plans.html
2. Click "Sign Up Free" 
3. Fill in email/password
4. Create new instance:
   - Name: codingcon-queue
   - Plan: Little Lemur (FREE)
   - Region: Mumbai (closest to you)
5. After created, view details
6. Copy the AMQP URL (format: amqp://username:password@host:5672/vhost)
7. Paste into .env:
   RABBITMQ_URL=amqp://...

Cost: FREE (Little Lemur tier)

═══════════════════════════════════════════════════════════════════════════════
2. REDIS - CACHING & SESSIONS
═══════════════════════════════════════════════════════════════════════════════

What it does: Caches data so database queries are faster

Setup (5 minutes):
────────────────────────────────────────────────────────────────────────────

1. Go to: https://console.upstash.com
2. Click "Sign Up"
3. Fill in email/password
4. Create Redis database:
   - Database Name: codingcon-cache
   - Region: ap-south-1 (Mumbai - closest to you)
   - Plan: FREE (256MB, 500K commands/month)
5. After created, click "Details"
6. Copy the Redis URL (format: redis://default:password@host:port)
7. Paste into .env:
   REDIS_URL=redis://...

Cost: FREE (free tier with 256MB)

═══════════════════════════════════════════════════════════════════════════════
3. VERIFY YOUR SETUP
═══════════════════════════════════════════════════════════════════════════════

After adding URLs to .env, restart backend:

Backend will now use:
✓ RabbitMQ for job queuing (faster submissions)
✓ Redis for caching (faster queries)
✓ Both improve performance automatically
