A. Subarray XOR Maximum

Easy Time Limit: 1.0s Memory Limit: 256MB Points: 500

Description

Given an array of $N$ integers, find the maximum bitwise XOR sum of any contiguous subarray. You must output the maximum value and the minimum length of the subarray achieving this maximum.

Input Format

The first line contains an integer $T$ ($1 \le T \le 100$) — the number of test cases.
Each test case consists of $N$ ($1 \le N \le 10^5$) followed by $N$ space-separated integers $A_1, A_2, \dots, A_N$.

Output Format

For each test case, print two space-separated integers: the maximum XOR sum and the length of the subarray.
