═══════════════════════════════════════════════════════════════════════════════
                    RENDER PRODUCTION DEPLOYMENT GUIDE
═══════════════════════════════════════════════════════════════════════════════

This guide shows how to deploy your backend to Render with RabbitMQ + Redis
configured for production (500+ concurrent users).

═══════════════════════════════════════════════════════════════════════════════
IMPORTANT: WHY CLOUD SERVICES FOR PRODUCTION?
═══════════════════════════════════════════════════════════════════════════════

Local Docker (Development):
  ✓ Works for testing
  ✗ Cannot be used in Render (localhost ≠ accessible from cloud)

Cloud Services (Production):
  ✓ Accessible from anywhere (Render can reach them)
  ✓ Managed & reliable (99.9% uptime)
  ✓ Easy to scale
  ✓ No maintenance needed

Your setup:
  ✓ MongoDB Atlas (already configured)
  ✓ RabbitMQ (need to add CloudAMQP)
  ✓ Redis (need to add Upstash)

═══════════════════════════════════════════════════════════════════════════════
STEP 1: SET UP CLOUDAMQP (RABBITMQ) - 5 MINUTES
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://www.cloudamqp.com/plans.html
2. Click "Sign Up Free"
3. Create account (email/password)
4. Create new instance:
   - Name: codingcon-queue
   - Plan: Little Lemur (FREE)
   - Region: Closest to you
5. Once created, click on instance name
6. In "Connection" section, copy the AMQP URL
   Format: amqp://username:password@host:5672/vhost
7. SAVE THIS URL - you'll need it next

═══════════════════════════════════════════════════════════════════════════════
STEP 2: SET UP UPSTASH REDIS - 5 MINUTES
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://console.upstash.com
2. Click "Sign Up"
3. Create account (email/password)
4. Create Redis database:
   - Name: codingcon-cache
   - Region: ap-south-1 (or closest to you)
   - Plan: FREE (256MB, 500K commands/month)
5. Once created, click on database name
6. In "Details", copy the Redis URL
   Format: redis://default:password@host:port
7. SAVE THIS URL - you'll need it next

═══════════════════════════════════════════════════════════════════════════════
STEP 3: CREATE RENDER ACCOUNT & CONNECT GITHUB
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://render.com
2. Click "Sign Up"
3. Choose "GitHub" (easier)
4. Authorize Render to access your GitHub
5. You should see your repositories

═══════════════════════════════════════════════════════════════════════════════
STEP 4: CREATE NEW WEB SERVICE ON RENDER
═══════════════════════════════════════════════════════════════════════════════

1. In Render dashboard, click "+ New" → "Web Service"
2. Select your GitHub repository (codingcon)
3. Fill in:
   - Name: codingcon-backend
   - Region: Frankfurt or closest
   - Branch: main
   - Runtime: Node
   - Build Command: npm install && npm run build
   - Start Command: npm run start
4. Click "Create Web Service"

═══════════════════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════════════════
STEP 6: GENERATE STRONG SECRETS
═══════════════════════════════════════════════════════════════════════════════

Open any terminal and run:

  node -e "console.log('JWT_SECRET=' + require('crypto').randomBytes(32).toString('hex'))"
  node -e "console.log('CRON_SECRET=' + require('crypto').randomBytes(32).toString('hex'))"

Copy the output values and paste into Render environment variables.

═══════════════════════════════════════════════════════════════════════════════
STEP 7: DEPLOY & MONITOR
═══════════════════════════════════════════════════════════════════════════════

1. Render automatically deploys when you push to GitHub
2. Watch the deployment log in Render dashboard
3. Once "Deployed" shows, your backend is live!

Monitor performance:
  - Check logs: Settings → Logs
  - Monitor CPU/Memory: Metrics tab
  - View errors: Settings → Logs → stderr

═══════════════════════════════════════════════════════════════════════════════
STEP 8: GET YOUR RENDER BACKEND URL
═══════════════════════════════════════════════════════════════════════════════

After deployment:
  1. Go to your Web Service in Render
  2. At top, you'll see: https://codingcon-backend.onrender.com
  3. This is your backend URL for production
  4. Use this to update CORS_ORIGIN in next.config.ts

═══════════════════════════════════════════════════════════════════════════════
STEP 9: DEPLOY FRONTEND TO VERCEL
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://vercel.com
2. Import your repository
3. Add environment variable:
   NEXT_PUBLIC_API_URL=https://codingcon-backend.onrender.com
4. Deploy

═══════════════════════════════════════════════════════════════════════════════
VERIFY EVERYTHING WORKS
═══════════════════════════════════════════════════════════════════════════════

Check backend health:

Check frontend:

  In Render logs, should see "✓ Connected to MongoDB"

RabbitMQ connection:

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Render can't reach RabbitMQ/Redis"
Solution: Make sure CloudAMQP + Upstash URLs are correct

Problem: "Backend fails to deploy"
Solution: Check Render logs for build errors
  - npm run build works locally? Try: cd backend && npm run build
  - Missing dependencies? Run: npm install

Problem: "Frontend can't reach backend"
Solution: Update CORS_ORIGIN in Render environment to your Vercel URL

Problem: "503 Service Unavailable"
Solution: Backend crashed. Check Render logs for errors
