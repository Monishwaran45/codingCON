TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "Too many connections" error
Solution:
  - Increase DB_POOL_SIZE to 75
  - Check if MongoDB max connections reached
  - Scale to Professional plan (more resources)

Issue: High CPU usage (>80%)
Solution:
  - Reduce MAX_JUDGE_JOBS to 2
  - Reduce QUEUE_CONCURRENCY to 1
  - Upgrade to Professional plan

Issue: OOM (Out of Memory) error
Solution:
  - Reduce DB_MIN_POOL_SIZE to 5
  - Reduce DB_POOL_SIZE to 25
  - Upgrade to Professional plan
  - Add Redis caching

Issue: WebSocket disconnects frequently
Solution:
  - Check pingInterval is 25000
  - Check network latency
  - Add keep-alive: true to client

Issue: Slow leaderboard updates
Solution:
  - Add Redis for caching
  - Reduce cache TTL
  - Check MongoDB indexes
